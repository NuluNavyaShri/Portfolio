# Navya Shri Nulu – Portfolio website

Files: `index.html`, `style.css`, `script.js`. No build step; it is plain HTML, CSS and JavaScript.

## Put it online free with GitHub Pages
1. On github.com, create a new public repository named `NuluNavyaShri.github.io`.
2. Upload `index.html`, `style.css` and `script.js` to the repository (Add file > Upload files) and commit.
3. Open the repository's Settings > Pages. Under "Build and deployment", choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
4. After a minute or two the site is live at https://nulunavyashri.github.io/Portfolio/
## Other free options
Netlify Drop (app.netlify.com/drop) and Vercel both accept this folder as is.

## Your own domain
Buy a domain such as navyashri.dev, then add it in your host's domain settings (GitHub Pages: Settings > Pages > Custom domain).

## Editing
Change text in `index.html`, colors at the top of `style.css`.
